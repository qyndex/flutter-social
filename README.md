# Flutter Social

Full-featured Flutter social app with feed, profiles, and real-time messaging using Riverpod state management and GoRouter navigation.

**Stack:** Flutter | **Complexity:** complex
**Tags:** `flutter`, `mobile`, `social`, `riverpod`, `gorouter`, `feed`, `messaging`, `material3`, `dart`

## Quick Start

```bash
flutter pub get
flutter run
```
